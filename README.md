# 📌 Dart DOM Experiment – Smart Task Manager

## 📖 Overview
This project is a web-based application developed using **Dart and the `dart:html` library** to demonstrate **Document Object Model (DOM) manipulation**.  

The application allows users to dynamically add, update, and delete tasks in real-time without reloading the page.

---

## 🎯 Aim
To study and implement the concept of the **Document Object Model (DOM)** using Dart, and to develop a dynamic web application that manipulates HTML elements, styles, and content interactively.

---

## 🧠 Concepts Covered
- DOM Tree Structure  
- Dynamic DOM Manipulation  
- Event Handling  
- CSS Styling via Dart  
- Real-time UI Updates  
- Cross-platform capabilities of Dart  

---

## 🚀 Features
- ✅ Add tasks dynamically  
- ✅ Delete tasks  
- ✅ Mark tasks as completed  
- ✅ Input field with Enter key support  
- ✅ Smooth animations (CSS + Dart)  
- ✅ No page reload (live updates)  

---

## 🛠️ Technologies Used
- Dart  
- `dart:html` library  
- HTML5  
- CSS3
